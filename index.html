Connecter cet appareil

Les vols sont enregistrés dans un dépôt GitHub privé. Cette page a besoin d'une clé d'accès pour les lire et les modifier. La clé reste dans le navigateur de cet appareil.

  1. Ouvrez GitHub : nouvelle clé d'accès.
  2. « Repository access » : choisissez « Only select repositories », puis le dépôt de données uniquement.
  3. « Permissions » : ajoutez « Contents » avec « Read and write ».
  4. Créez la clé, copiez-la et collez-la ci-dessous.
